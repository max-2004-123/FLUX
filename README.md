# FLUX

隨手收錄想法、提醒與連結，讓每一筆紀錄都能在需要的時候找回來。這個儲存庫是 FLUX 的網頁版部署檔，可在電腦與手機瀏覽器使用。

## 功能

- **快速收錄**：記下文字與網址，編輯標題、摘要與標籤，或依文字、類型及標籤搜尋。
- **提醒便利貼**：使用 `#提醒` 標籤建立可勾選的提醒；移除便利貼不會刪除原紀錄。
- **連結收藏與每日小報**：集中查看收藏和小報，依日期瀏覽、搜尋及開啟來源。每日小報須另外設定雲端排程。
- **AI 整理**：使用自己的 Gemini API 金鑰，協助產生標題、摘要與標籤；沒有金鑰仍可手動收錄和編輯。
- **Google 同步與行事曆**：透過自行部署的 Apps Script 在裝置間同步，並在確認後新增行事曆事件。
- **檔案互傳**：設定 Google Drive 中轉站後，可在裝置間上傳與下載檔案。
- **手機使用**：可透過 Safari 加入主畫面；完成首次載入與離線快取後，可離線收錄。AI 和同步需要網路。

## 開始使用

1. 開啟部署後的 FLUX 網站，直接輸入文字或網址並收錄。
2. 如需 AI 整理，在「設定與連線」填入自己的 Gemini API 金鑰。
3. 如需跨裝置同步，依設定頁指示部署 Google Apps Script，再填入部署網址與同步密語。
4. 使用 iPhone 時，可在 Safari 分享選單選擇「加入主畫面」。

各項連線均為選用功能。不同瀏覽器與裝置的本機資料不會自動共享；完成同步設定後才能互通。

## 本機預覽與部署

此儲存庫根目錄即靜態網站內容。可使用任何靜態 HTTP 伺服器預覽，例如在此目錄執行：

```sh
python -m http.server 8000
```

再開啟 `http://localhost:8000`。請勿直接以 `file://` 開啟，因為網站使用 ES modules 和 service worker。部署時請保留目錄結構並上傳完整檔案；修改靜態資源後，更新 `sw.js` 的快取版本，讓離線版本能取得更新。

## 資料與隱私

紀錄先存於瀏覽器本機；清除網站資料可能導致尚未同步的紀錄遺失。連線密鑰預設保存在工作階段，可自行選擇在裝置上記住；選擇記住時會以未加密方式儲存。一般 AI 整理會將選取的文字送至 Google；連結小報功能另會將待處理連結及可取得的頁面內容交由 Gemini 處理。

提醒便利貼不是定時通知；行事曆事件需由使用者確認後才會新增。
